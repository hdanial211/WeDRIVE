## 2. Peranan 9 Alatan Pintar & Matlamat Operasinya

### 1. Playwright CLI (Automasi Ujian E2E)
- **Fungsi:** Menjalankan ujian automatik merentas semua butang, borang, dan aliran aplikasi di pelayar secara berasingan di bawah folder `tests/`.
- **Kelebihan:** Menghapuskan pembaziran masa ujian manual berjam-jam dan menjamin **100% Pass Rate** sebelum pelepasan versi.

### 2. Supabase MCP (Pengurusan Pangkalan Data Tanpa Beban Backend)
- **Fungsi:** Menguruskan pangkalan data PostgreSQL, skema jadual, keselamatan RLS, dan fungsi pangkalan data secara lancar.
- **Kelebihan:** Menghapuskan keperluan membina pelayan backend manual dari awal.

### 3. Strix Security Audit (Simulasi Penembusan Etika)
- **Fungsi:** Mengimbas dan menguji aplikasi persis penggodam sebenar untuk mengesan sebarang kelemahan keselamatan.
- **Kelebihan:** Memastikan sifar kebocoran data peribadi (PII) dan menyediakan bahan kajian keselamatan bagi tesis FYP 2.

### 4. Skill UI for Front-End (Kejuruteraan Terbalik Apple HIG)
- **Fungsi:** Menterjemah reka bentuk laman web rujukan kepada spesifikasi kod visual Apple HIG berkualiti tinggi.
- **Kelebihan:** Membina UI premium (Bento grid, kaca lut sinar, geometri bulat 1:1 sempurna) tanpa arahan berulang yang panjang.

### 5. Context7 MCP (Dokumentasi Terkini & Sifar Halusinasi)
- **Fungsi:** Mengambil dokumentasi langsung dan versi API paling terkini secara langsung menerusi alur kerja `resolve-library-id` $\rightarrow$ `query-docs`.
- **Kelebihan:** Menghapuskan kod lapuk, parameter salah, atau tekaan palsu.

### 6. Stitch MCP (Penjanaan Antaramuka Gemini 3.8 UHQ)
- **Fungsi:** Menjana reka bentuk skrin berasaskan teks dan melaraskan varian reka bentuk ultra berkualiti tinggi.
- **Kelebihan:** Menyediakan templat reka bentuk yang menepati kod reka bentuk WeDRIVE (`projectId: 1862124494843018493`).

### 7. Composio (Integrasi & Automasi Perkhidmatan)
- **Fungsi:** Menyediakan penyambung luaran bagi automasi aliran kerja dan pengurusan perkakas sokongan.
- **Kelebihan:** Memperluas integrasi alatan luar ke dalam aliran kerja pintar.

### 8. Graphify (Navigasi Graf Pengetahuan & Penjimatan Token)
- **Fungsi:** Memetakan seluruh nod, komponen, dan fungsi sistem ke dalam graf pengetahuan di `graphify-out/`.
- **Kelebihan:** Menghapuskan pembacaan fail secara pukal (*bulk file reading*) dan menjimatkan kuota token AI.

### 9. Chrome DevTools MCP (Pemeriksaan Halaman Perspektif Pengguna)
- **Fungsi:** Memeriksa keadaan visual, DOM, konsol, dan elemen aktif di pelayar pada tab sedia ada sebelum sebarang kod diubah.
- **Kelebihan:** Menjamin perubahan kod dibuat tepat pada komponen yang dilihat oleh pengguna tanpa membuka banyak tab.
